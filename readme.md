# Russian Documentation Hub for Web3 & DeFi

Copyright (c) 2005-2023, Evgeny Zakharenko, TechWriters.ru info@techwriters.ru

Welcome, an open initiative to make complex Web3 and DeFi protocols accessible for the Russian-speaking community.

## 🌍 Mission
To create high-quality, open-source documentation, guides, glossaries, and educational materials in Russian for the most relevant and active Web3 protocols.

## 🧩 What We Do
- Translate and adapt technical documentation from Yearn, Frax, Curve, and others
- Create infographics and visual diagrams for easier understanding
- Maintain a full Sphinx-based documentation website: [web3.techwriters.ru](http://web3.techwriters.ru)
- Provide multilingual glossaries of DeFi concepts
- Produce educational content (YouTube, guides, explainers)

## ✅ Current Status
- ✅ Yearn V3 documentation in Russian (in progress)
- ✅ Live website with glossary and index
- ✅ Automated deployment and open GitHub repository
- ✅ Web3 & DeFi comparison article (available at homepage)
