План работ ThisWeb3 (Roadmap)
=============================

Проект развивается поэтапно. Ниже представлен ориентировочный план развития на ближайшие месяцы.

Этап 1: Весна 2025
-------------------
- Перевод и публикация документации Yearn V3 (ядро, стратегии, интерфейсы)
- Настройка инфраструктуры сайта и деплоя (Sphinx + GitHub + FTP)
- Подключение глоссариев и перекрёстных ссылок
- Создание инфографики (архитектура Yearn V3, токенизация стратегий)
- Запуск YouTube-канала и публикация первого видео-обзора

Этап 2: Лето 2025
------------------
- Добавление документации по Frax Finance и Curve
- Выпуск серии видеороликов и кратких гайд-обзоров
- Автоматизация обновлений документации и GitHub Actions
- Подключение мультиязычной поддержки
- Первичная подача заявки на грант в Yearn, Gitcoin, Arbitrum

Этап 3: Осень 2025
-------------------
- Перевод документации Aave, Lido, Stargate
- Расширение сайта: сравнение протоколов, разделы для пользователей и разработчиков
- Добавление интерактивных элементов и поддержки мобильных устройств
- Публикация методичек и коротких обучающих PDF-гайдов

Этап 4: Зима 2025–2026
------------------------
- Формирование базы знаний Web3 на русском языке
- Интеграция со сторонними DAO-доками через pull requests
- Публикация отчёта о проделанной работе и подготовка к повторному гранту
- Формирование комьюнити вокруг проекта (TG, Twitter, GitHub Issues)
