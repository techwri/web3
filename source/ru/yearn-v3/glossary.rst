Глоссарий Yearn V3
==================

.. glossary::

   Vault
     Контракт-хранилище по стандарту ERC-4626, предназначенный для коллективного управления активами пользователей. Принимает депозиты, выпускает доли и распределяет средства между стратегиями.

   Strategy
     Контракт, реализующий определённую стратегию получения дохода. Получает капитал от Vault'ов и управляет им для генерации прибыли.

   Tokenized Strategy
     Стратегия, реализованная в виде отдельного ERC-4626-хранилища. Может принимать депозиты как от Vault'ов, так и напрямую от пользователей. Поддерживает повторное использование.

   Vault Factory
     Фабрика для создания новых Vault'ов. Управляется DAO Yearn, работает без необходимости одобрения. Позволяет гибко и быстро запускать хранилища.

   Yearn Governance
     Механизм управления экосистемой Yearn через DAO. Участники голосуют за изменения, внедрение стратегий, параметры комиссий и другие решения.

   4626 Router
     Контракт, обеспечивающий простой ввод и вывод средств в хранилища и стратегии. Унифицированный интерфейс для пользователей и интерфейсов.

   Registry
     Реестр активных Vault'ов и стратегий. Хранит метаинформацию и облегчает интеграции с другими протоколами.

   Debt Allocator
     Компонент, распределяющий капитал Vault'а между подключёнными стратегиями по заданной логике.

   Accountant
     Контракт, рассчитывающий и собирающий комиссии протокола. Поддерживает разные типы сборов.

   Deposit/Withdraw Limit Modules
     Модули ограничения объёма ввода и вывода. Используются для управления рисками и обеспечением стабильности протокола.

   Swappers
     Контракты обмена активов внутри стратегий. Позволяют конвертировать токены без выхода из системы (например, через Curve, Uniswap).

   APR Oracles
     Оракулы, предоставляющие значения текущей годовой доходности (APR) по стратегиям и хранилищам. Используются для аналитики и аллокации средств.

   Reinvest profit
     Процесс автоматического направления прибыли обратно в стратегию или Vault для увеличения общего дохода.

   Modular architecture
     Архитектура, основанная на независимых компонентах, которые можно гибко подключать, отключать и обновлять без вмешательства в ядро.

   Multi Asset Vault
     Хранилище, способное распределять активы по нескольким стратегиям и поддерживать работу с несколькими токенами одновременно
